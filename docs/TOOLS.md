# Tools

This is the tool list exposed by the MCP server, taken from `TOOL_SCHEMAS` in
`packages/shared/src/tools.ts`. For parameters, ask your client to list the tool schemas or read the
source; each tool carries a full JSON schema.

The last column marks high-risk tools and the switch that controls them. Switches live under the
`highRiskTools` key in the extension's `chrome.storage.local`. Cookies, storage values, intercept,
permission grants, clipboard and recording are off until the key is exactly `true`. JavaScript and
upload are on unless the key is exactly `false`. Every tool is also subject to the site policy (see
[SECURITY-AND-CAPABILITIES.md](SECURITY-AND-CAPABILITIES.md)).

## Tools provided by the native host

These are registered by the native server, not the extension.

| Tool                                                                                             | Purpose                                                                                  |
| ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| `chrome_panel_open`                                                                              | Open an app-style window showing HTML you supply, to show content and capture an answer. |
| `chrome_panel_wait`                                                                              | Wait for what the person submits in a panel.                                             |
| `chrome_panel_update`                                                                            | Update the content of an open panel.                                                     |
| `chrome_panel_close`                                                                             | Close a panel.                                                                           |
| `flow.<slug>`                                                                                    | One tool per published flow, created dynamically.                                        |
| `google_auth_status`, `google_auth_login`, `google_auth_logout`                                  | Check, start and clear Google authorization.                                             |
| `google_api_call`, `google_api_schema`                                                           | Call a Google API or read its schema. Non-GET calls are dry-run by default.              |
| `google_sheets_read`, `google_sheets_append`, `google_sheets_update`, `google_sheets_ensure_tab` | Read and write Google Sheets.                                                            |
| `google_docs_read`, `google_docs_append_text`                                                    | Read a Google Doc and append text to it.                                                 |

The Google tools are gated by the `allowAuthTools` policy. See [google-workspace.md](google-workspace.md).

## Not exposed

`chrome_inject_script`, `chrome_send_command_to_inject_script`, `chrome_userscript` and
`search_tabs_content` exist in the source but are disabled and are not offered to clients.
